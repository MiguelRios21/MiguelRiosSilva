# Módulo de Pedidos e Entregas

## Objetivo do repositório

Este repositório tem como objetivo documentar a estrutura analítica do projeto (EAP) do **Módulo de Pedidos e Entregas**, organizando suas principais entregas em níveis hierárquicos para facilitar o planejamento, o acompanhamento e a compreensão do escopo do projeto.
